# LR-and-RF-models
Predicting house prices in Tashkent, Uzbekisan using Supervised Learning such as Linear Regression and Random Forest Models

This project aims to build and compare supervised learning models for forecasting household prices using Linear Regression and Random Forest models. The dataset includes features like location, district, size, price, level, max_levels and rooms. It was developed as part of a research project in Artificial Intelligence in Mohir Dev platform.

# Features
Data Understanding
Data preprocessing and cleaning
Model training: Linear Regression, Random Forest
Evaluation using RMSE, MAE
Visualizations and result comparison

# Dataset
The dataset used is https://raw.githubusercontent.com/anvarnarz/praktikum_datasets/main/housing_data_08-02-2021.csv
